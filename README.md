# 🎰 Crypto Roulette — Proportional TON Roulette

Многопользовательская пропорциональная рулетка с физикой шайбы.  
Telegram Mini App с серверной архитектурой (authoritative server).

## Структура проекта

```
roulette-game/
├── server/
│   ├── server.js          # Авторитарный сервер (логика, физика, боты)
│   └── package.json       # Зависимости
├── client/
│   └── index.html         # Фронтенд (Canvas + UI)
└── README.md
```

## Быстрый старт

```bash
# 1. Установить зависимости
cd server
npm install

# 2. Запустить сервер
npm start
# или для разработки (авто-рестарт):
npm run dev

# 3. Открыть в браузере
# http://localhost:3000
```

## Что реализовано

### Сервер (server.js)
- **Авторитарная архитектура** — вся логика и физика на сервере
- **Полный игровой цикл**: ожидание → таймер → раскрутка → полёт → остановка → результат
- **Физика шайбы**: спавн, импульс, отскоки от стен, трение, остановка
- **Provably Fair**: серверный seed + публичный seed → SHA-256 хэш
- **Treemap-секторы**: квадратная арена делится пропорционально ставкам
- **Умные боты**:
  - 4 кластера: массовка (0.1-10), мидлы (10-100), акулы (100-1000), киты (1000-10000)
  - Привязка к МСК-часовому поясу
  - "Эффект снайпера" — крупные ставки в последние 1-3 сек
- **Socket.IO** — реалтайм синхронизация
- **Валидация** — все ставки проверяются на сервере

### Клиент (index.html)
- **Canvas-арена** с treemap-секторами и аватарками
- **Интерполяция шайбы** — плавное движение между серверными обновлениями
- **Эффекты**: glow, speed trail, spinning arrow, sector highlighting
- **UI**: header (топ/последняя игра), статус, таймер, footer, панель ставок
- **Winner popup** с конфетти
- **Адаптивность** — работает на мобильных

## Деплой на Render

1. Создай Web Service на render.com
2. Укажи путь: `server/`
3. Build command: `npm install`
4. Start command: `npm start`
5. Переменные: `PORT=3000` (Render подставит свой)

На бесплатном тарифе Render засыпает через ~15 мин без запросов. Чтобы сервер работал 24/7,
он раз в 4 минуты сам стучится в свой адрес (`RENDER_EXTERNAL_URL`, Render задаёт его сам).
Если сервер всё же уснул, его будит `.github/workflows/keepalive.yml` (из ветки `main`).
Для постоянной истории/балансов между перезапусками задай `SUPABASE_URL` и `SUPABASE_KEY`.

## Интеграция с Telegram Mini App

Для запуска как Mini App через BotFather:
1. Создай бота через @BotFather
2. `/newapp` → укажи URL деплоя
3. Клиент автоматически подхватит Telegram Web App API
